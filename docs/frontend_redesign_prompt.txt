Playoff Hoops is a fantasy basketball application focused on NBA playoffs.
Users register, create or join leagues, draft 8 real NBA players, track
daily scoring with playoff-round multipliers (R1 x1.0, Semis x1.25, CF x1.5,
Finals x2.0), monitor "hot/cold" streaks (last 5 games vs season average),
and generate AI scouting reports via gpt-4o-mini. Data is real: 791 players,
3.778 playoff games, 88.603 box scores, pulled from the Kaggle dataset
`eoinamoore/historical-nba-data-and-player-box-scores` (2023-24, 2024-25,
2025-26 seasons).

PLAYER IMAGERY — CRITICAL
================================================================

Player IDs in the database come from nba_api (stats.nba.com). The NBA CDN
exposes official headshots at a predictable URL:

  https://cdn.nba.com/headshots/nba/latest/1040x760/{player_id}.png

Team logos (NBA team_id, already stored in nba_teams.team_id):

  https://cdn.nba.com/logos/nba/{team_id}/primary/L/logo.svg

Build a `<PlayerAvatar>` component:

  props: playerId (number), size ("xs"|"sm"|"md"|"lg"|"xl"), teamId?, className?
  sizes: xs=24 sm=32 md=48 lg=72 xl=128 (square, rounded-full, object-cover object-top)
  - Renders <img src="https://cdn.nba.com/headshots/nba/latest/1040x760/${playerId}.png" />
  - Background: solid team color if teamId provided (use a teamColor map),
    otherwise bg-[--color-bg-elev-2].
  - On error (player not in CDN): fall back to initials in font-display
    uppercase over the team color background.
  - loading="lazy", decoding="async".

Build `<TeamLogo>` component the same way for NBA team logos. The <img>
should sit on a dark circle with ring-1 ring-[--color-border].

Every player listing, every leaderboard row, every roster slot, every
draft board cell MUST show the PlayerAvatar. This is the single biggest
visual differentiator from the current frontend.

Build a `teamColors.ts` map keyed by NBA team abbreviation, e.g.:

  { LAL: '#552583', BOS: '#007A33', GSW: '#1D428A', MIA: '#98002E', ... }

Apply the team color as a 3px left border on player rows (border-l-[3px]
border-l-[teamColor]) and as the ring on PlayerAvatar.
