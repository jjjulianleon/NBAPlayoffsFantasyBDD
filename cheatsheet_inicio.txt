REQUISITOS PREVIOS

================================================================
1) BASE DE DATOS
================================================================

1.1 Verifica que Postgres este arriba:
    sudo systemctl status postgresql
    # si no esta activo:
    sudo systemctl start postgresql

1.2 Crear usuario y DB (solo la primera vez — si ya existe salta
    este paso; un error "already exists" no rompe nada):
    sudo -u postgres psql <<'EOF'
    CREATE USER playoff WITH PASSWORD 'playoff_dev';
    CREATE DATABASE playoff_hoops OWNER playoff;
    EOF

1.3 Cargar schema, vistas, procedures y triggers
    (desde la raiz del proyecto):
    PGPASSWORD=playoff_dev psql -h localhost -U playoff -d playoff_hoops -f data/schema.sql
    PGPASSWORD=playoff_dev psql -h localhost -U playoff -d playoff_hoops -f data/views.sql
    PGPASSWORD=playoff_dev psql -h localhost -U playoff -d playoff_hoops -f data/procedures.sql
    PGPASSWORD=playoff_dev psql -h localhost -U playoff -d playoff_hoops -f data/triggers.sql

1.4 (Primera vez unicamente) Cargar datos NBA desde Kaggle
    — descarga ~880 MB, tarda varios minutos:
    source venv/bin/activate           # ver paso 2 si el venv aun no existe
    python data/seed_kaggle.py

1.5 Restringir pool de jugadores a los 16 equipos del playoff
    actual (idempotente — reejecutable tras cada seed):
    PGPASSWORD=playoff_dev psql -h localhost -U playoff -d playoff_hoops -f data/seed_playoffs.sql

1.6 Smoke test — debe imprimir filas:
    PGPASSWORD=playoff_dev psql -h localhost -U playoff -d playoff_hoops \
      -c "SELECT COUNT(*) AS jugadores FROM players; SELECT COUNT(*) AS partidos FROM games;"

================================================================
PRUEBAS MULTI-USUARIO (liga + draft)
================================================================

Usa DOS navegadores distintos (Chrome normal + Chrome incognito, o
Chrome + Firefox). Cada navegador tiene su propio localStorage, asi
que los tokens JWT de cada cuenta no se pisan.

Flujo tipico:
  Navegador A: registrar/login como "comisionado" -> crear liga -> crear equipo
  Navegador B: registrar/login como "miembro"     -> unirse a liga -> crear equipo
  Navegador A (comisionado): Iniciar draft
  Alternar turnos entre ambos navegadores para draftear.

Si sale "Solo el comisionado puede iniciar el draft" estando seguro
que es la cuenta correcta, casi siempre es porque el token en
localStorage pertenece a otra cuenta. DevTools -> Application ->
Local Storage -> verificar el JSON "user" y el "token". Si dudas,
logout + borrar ambos keys + login de nuevo.


================================================================
TROUBLESHOOTING RAPIDO
================================================================

- Postgres "peer authentication failed":
    Se debe usar PGPASSWORD y -h localhost -U playoff (no sudo -u postgres).

- "relation xxx does not exist":
    Faltaron los scripts 1.3 o el seed del 1.4/1.5.

- Backend: "ModuleNotFoundError" al hacer uvicorn:
    Olvidaste activar el venv (paso 2.3).

- Frontend: 502/404 llamando /api/*:
    El backend no esta arriba, o esta en otro puerto distinto a 8000.

- Puerto 8000 o 5173 ocupado:
    lsof -i :8000        # para ver que proceso lo tiene
    lsof -i :5173
    kill -9 <PID>        # si corresponde

- Resetear la BD por completo (borra TODO, cuidado):
    sudo -u postgres psql -c "DROP DATABASE playoff_hoops;"
    # y repetir desde 1.2
